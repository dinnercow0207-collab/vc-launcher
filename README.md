# VC Launcher

Discordのような「テキストチャット + ボイスチャット(VC) + 画面共有」ができる、
自分たち専用の小さなサイトです。ユーザー登録はユーザー名とパスワードだけ。
最大50人程度の少人数利用を想定しています。

## できること
- ユーザー名+パスワードだけで登録・ログイン
- サーバー(コミュニティ)の作成、招待コードでの参加
- テキストチャンネル / ボイスチャンネルの作成
- リアルタイムのテキストチャット
- VC(音声通話)、画面共有
- 管理者専用画面(`/admin.html`): 登録者数・オンライン人数などの統計、迷惑行為をするユーザーのBAN/BAN解除

## できないこと・注意点
- 通知機能はありません
- ショップ・着せ替え機能はありません
- VCは「メッシュ接続」という方式なので、**1つの通話部屋につき目安4〜6人程度**が快適に動く上限です。それ以上になると、参加者それぞれのPC負荷・通信量が増えます
- 相手の回線環境によっては音声/画面共有がうまく繋がらないことがあります(TURNサーバーを追加すると改善します。下記「発展」参照)

## 1. 手元での動作確認(任意)

パソコンにNode.js(18以上推奨)がインストールされていれば、公開前に手元で試せます。

```bash
cd vc-launcher
npm install
npm start
```

ブラウザで `http://localhost:3000` を開くと動作確認できます。
Node.jsをインストールしていない場合は、この手順は飛ばして次に進んでください
(Render上でインストールされるので問題ありません)。

## 2. GitHubにアップロードする

すでに `dinnercow0207-collab/vc-launcher` というリポジトリを連携済みとのことなので、
このフォルダの中身をそのリポジトリにアップロード(push)してください。

GitHubのWeb画面から直接アップロードする場合:
1. リポジトリのページを開く
2. 「Add file」→「Upload files」
3. このフォルダの中身(`server/`, `public/`, `package.json`, `.gitignore` など)をすべてドラッグ&ドロップ
4. 「Commit changes」で確定

---

## 3. Renderでデプロイする

1. Renderのダッシュボードで、さっき見せてもらった画面(New Web Service → `vc-launcher` を選択)からそのまま進める
2. 設定項目は以下の通り入力:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
3. 「Environment」セクションで環境変数を1つ追加:
   - Key: `SESSION_SECRET`
   - Value: 好きなランダムな文字列(例: `k3j29fj2l0fkalsjf`など、他人にはわからない文字列でOK)

   続けてもう1つ環境変数を追加し、自分を管理者にします:
   - Key: `ADMIN_USERNAME`
   - Value: 管理者にしたい**自分のユーザー名**(これから新規登録するときと同じ文字列)

   ※ `ADMIN_USERNAME` に指定したユーザー名で**新規登録すると自動的に管理者になります**。
   　 すでに登録済みのユーザー名を指定した場合は反映されないので、その場合は一度そのアカウントを
   　 削除して登録し直すか、Claude Codeで管理者への昇格を手伝ってもらってください。
4. 「Create Web Service」をクリック

数分後、`https://(サービス名).onrender.com` のようなURLが発行されて、そこにアクセスすれば
サイトが使えるようになります。

### 注意: 無料プランのスリープについて
Renderの無料プランは、一定時間アクセスがないとサーバーが自動的にスリープします。
次にアクセスがあったときに自動で起き上がりますが、最初の1回だけ表示に数十秒かかることがあります。
毎回すぐ使いたい場合は有料プランへのアップグレードを検討してください。

---

## 4. 発展: 音声が繋がりにくいときは(TURNサーバー)

一部のネットワーク環境(会社・学校のWi-Fiなど)では、直接接続ができずVCが繋がらないことがあります。
その場合は「TURNサーバー」という中継サーバーが必要です。

`server/index.js` ではなく `public/js/app.js` の中の `ICE_SERVERS` という部分に、
無料枠のあるTURNサービス(例: metered.ca)から発行された情報を追記すると改善します。
このあたりはClaude Codeで一緒に進めるとスムーズです。

## フォルダ構成

```
vc-launcher/
├── package.json
├── server/
│   ├── index.js   ← サーバー本体(認証API・チャンネルAPI・Socket.io)
│   ├── db.js      ← データベース(SQLite)の設定
│   └── auth.js    ← 登録・ログインの処理
└── public/
    ├── login.html ← ログイン/登録画面
    ├── app.html   ← メイン画面
    ├── admin.html ← 管理者専用画面
    ├── css/style.css
    ├── js/app.js   ← チャット・VC・画面共有のクライアント側処理
    └── js/admin.js ← 管理画面のクライアント側処理
```

## 管理者としてできること
- `/admin.html` にアクセス(サイドバーの「🛡️ 管理画面」からも移動できます。管理者アカウントにのみ表示されます)
- 登録ユーザー数、現在オンラインの人数、BAN中のアカウント数、サーバー数、総メッセージ数を確認
- ユーザー一覧から「BANする」を押すと、そのアカウントはログインできなくなり、通話・チャットに接続中だった場合は即座に切断されます
- 「BAN解除」でいつでも元に戻せます
- 管理者アカウント自身や、他の管理者アカウントはBANできません(誤操作防止)
